## SSM Parameter Store
---
- Config 와 Secret 을 저장하는 보안 스토리지다
- KMS 를 이용한 암호화를 선택적으로 적용할 수 있다
- Serverless 이며 확장성과 내구성을 갖추고 SDK 사용이 간편하다
- Config 와 Secret 의 버전을 추적한다
- IAM 으로 접근을 제어한다
- Amazon EventBridge 로 알림을 전송할 수 있다
- CloudFormation 과 통합된다

### Parameter Policies (for advanced parameters)
- Parameter 에 TTL(만료일)을 지정해 비밀번호와 같은 민감 정보를 강제로 갱신하거나 삭제하도록 정책을 지정할 수 있다
- 여러 정책을 함께 지정할 수 있다

## SSM Session Manager
---
- EC2 인스턴스와 온프레미스 서버에 셸 세션을 시작할 수 있다
- SSH 접속, bastion host, SSH 키가 필요 없다
- 22번 포트를 열지 않아도 되므로 보안상 유리하다
- Linux, macOS, Windows 를 지원한다
- 세션 로그를 S3 또는 CloudWatch Logs 로 전송할 수 있다

## Run Command
---
- Document(스크립트)를 실행하거나 단일 명령을 실행한다
- 여러 인스턴스에 동시에 명령을 실행할 수 있다
- SSH 가 필요 없다
- 명령 실행 결과는 AWS Console 에서 확인하거나 S3 버킷 또는 CloudWatch Logs 로 전송할 수 있다
- 명령 실행 상태를 SNS 로 알릴 수 있다
- IAM, CloudTrail 과 통합된다
- EventBridge 로 호출할 수 있다

## Patch Manager
---
- 관리 대상 인스턴스의 패치 작업을 자동화한다
- OS 업데이트, 애플리케이션 업데이트, 보안 업데이트를 대상으로 한다
- EC2 인스턴스와 온프레미스 서버를 지원한다
- Linux, macOS, Windows 를 지원한다
- 필요할 때 즉시 패치하거나 Maintenance Windows 를 이용해 정해진 일정에 패치한다
- 인스턴스를 스캔해 누락된 패치를 담은 규정 준수 보고서를 생성한다

## Maintenance Windows
---
- 인스턴스에 대한 작업을 언제 수행할지 일정을 정의한다
- Maintenance Window 의 구성 요소는 다음과 같다
	- Schedule: 실행 일정
	- Duration: 지속 시간
	- Set of registered instances: 등록된 인스턴스 집합
	- Set of registered tasks: 등록된 작업 집합

## Automation
---
- EC2 인스턴스를 비롯한 AWS 리소스의 일상적인 유지보수와 배포 작업을 단순화한다
- Automation Runbook = EC2 인스턴스나 AWS 리소스에 수행할 작업을 정의한 SSM Document
